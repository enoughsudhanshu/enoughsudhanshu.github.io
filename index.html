Project Case Studies

Bhishmaa ERP

Bhishmaa ERP Platform

A modular ERP system that connects operations, finance, and analytics for education and service workflows.

Problem

Manual workflows, spreadsheet-driven planning, and disconnected team reporting slowed decision-making.

Solution

Built a Python + Flask platform with PostgreSQL, role-based access, dashboards, and scheduled automation.

Architecture

Frontend dashboard → Flask API → PostgreSQL → background workers for report generation.

Tech Stack: Python, Flask, PostgreSQL, Docker Deployment: Linux, Docker, Cloudflare Challenges: Data sync, access control, analytics latency Future Scope: reporting automation, API integrations, audit logging
PostgreSQL Automation

PostgreSQL Automation

Backup and recovery workflows designed to reduce risk for production data systems.

Problem

Manual backups and inconsistent retention exposed systems to data loss.

Solution

Created scheduled backup pipelines, audit logging, and automated restore tests using cron and shell automation.

Architecture

PostgreSQL → backup scripts → encrypted archives → cloud storage with retention rules.

Tech Stack: PostgreSQL, Bash, Linux, S3 Deployment: Linux cron pipelines, containerized tools Challenges: scheduling, secure storage, restore validation Future Scope: incremental backups, alerting, self-service recovery
Cloud Deployment

Cloud Deployment

A Linux-based deployment workflow for Flask applications with secure tunneling and container orchestration.

Problem

Deployment was unreliable, with inconsistent staging and no repeatable release process.

Solution

Implemented Docker pipelines, Linux host orchestration, Cloudflare tunnels, and versioned deployments.

Architecture

Repo → CI build → Docker image → Linux host → Cloudflare tunnel → monitoring.

Tech Stack: Docker, Linux, Cloudflare, Flask Deployment: Container pipelines, secure tunnels Challenges: networking, uptime, release consistency Future Scope: blue/green deploys, rollout automation, telemetry
